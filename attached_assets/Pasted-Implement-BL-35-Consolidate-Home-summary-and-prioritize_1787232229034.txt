Implement BL-35 — Consolidate Home summary and prioritize activity.

Use the completed Task #294 investigation as the repository-backed implementation plan.

Goal:
Make useful Home activity appear substantially earlier on mobile by compacting the existing profile/social summary, without changing BaseLodge data semantics or activity logic.

Implement the following approved hierarchy:

1. Welcome/profile access
2. Compact rider type · skill level · pass identity line
3. Upcoming Trips · Mountains Visited · Wishlist Mountains
4. Compact Friends’ Passes summary
5. Happening
6. Ideas
7. Lightweight availability control / remaining secondary activity

  SKIER · ADVANCED · EPIC

PERSONAL STATS
