--------------------------------------------------
BL-163 GOAL
--------------------------------------------------

BaseLodge should stop broadly prefetching routes/resources simply because they might be visited.

Replace that behavior later with bounded, intent-based prefetching where it provides a measurable navigation benefit.

This investigation must determine the current architecture and recommend the smallest safe implementation.

Do NOT implement the recommendation yet.
