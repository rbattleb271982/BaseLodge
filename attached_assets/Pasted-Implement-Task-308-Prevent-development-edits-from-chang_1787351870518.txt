Goal
Make it impossible by default for interactive development, tests, file-watch reloads, or routine Flask/Alembic commands to accidentally connect to or mutate the production Supabase database.
The investigation established that:
the interactive Replit workspace has access to production Supabase credentials;
app.py currently selects Supabase based on credential availability rather than a trustworthy runtime environment;
importing app.py executes database-mutating startup routines;
Flask CLI commands and watcher reloads can therefore execute those routines against production;
production currently has unreconciled schema state, so the legacy startup migration routines cannot simply all be removed yet.
