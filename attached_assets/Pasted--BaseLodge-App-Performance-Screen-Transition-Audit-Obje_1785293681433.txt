# BaseLodge — App Performance & Screen Transition Audit

## Objective

Perform a comprehensive, evidence-based performance audit of BaseLodge to identify where users experience slow loading, delayed navigation, lag between screens, or unnecessary waiting.

This is an investigation and recommendation task only.

Do not make code changes.

Do not refactor.

Do not create commits.

The goal is to determine:

1. Which screens and user flows are slow.
2. What specifically causes each delay.
3. Which improvements would have the greatest impact on overall app speed.
4. Which fixes are low risk versus architecturally significant.

Base every finding on actual code paths, database queries, network requests, templates, JavaScript, native behavior, configuration, and available logs.

Do not speculate without evidence.

---

# Scope

Audit performance across:

- Flask server routes
- Database queries
- SQLAlchemy relationships
- API endpoints
- Jinja templates
- JavaScript
- Capacitor WebView behavior
- Native-to-web navigation
- Authentication
- Page redirects
- External services
- Image and asset loading
- Notifications
- Background tasks
- Session handling
- Startup behavior
- Screen-to-screen navigation

Review both actual technical performance and perceived user performance.

Review navigation between every major screen.

Look for:

- Multiple redirects
- Full page reloads

- Duplicate API calls

- JavaScript waiting unnecessarily

- WebView/browser transitions
- Flash pages
- Intermediate pages
- Duplicate rendering

For every transition include:

- From screen
- To screen
- Route
- Cause
- Delay type
- Severity
- Evidence
- Recommended improvement

# Task 3 — Database Performance Audit

Inspect all important routes.

Look for:

- N+1 queries
- Queries inside loops
- Missing eager loading
- Missing indexes
- Large unbounded queries
- Loading entire ORM objects unnecessarily
- Duplicate queries
- Relationship-triggered queries
- Python filtering instead of SQL
- Expensive aggregates
- Queries from templates
- Repeated calculations

Pay particular attention to:

- Dashboard
- Friends
- Friend profile
- Trips
- Trip detail
- Notifications
- Invite flows
- Planning
- Overlap calculations

For every issue include:

- File
- Function
- Query
- Evidence
- User impact
- Suggested improvement
- Index recommendation
- Risk

Audit all significant Flask routes.

- Large JSON payloads

- Likely Bottleneck
- Critical Bottleneck
