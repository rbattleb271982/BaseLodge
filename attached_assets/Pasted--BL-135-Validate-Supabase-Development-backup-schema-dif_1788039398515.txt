bl317_startup_schema

bl52_trip_stay

- whether it executes raw SQL
- whether it has any destructive operation
- whether downgrade is implemented

- models/columns currently expected
- indexes/constraints currently expected
- trip-stay-related schema expected by current code

## G. Data-risk analysis

- whether type conversions occur
- whether rows are deleted/rewritten
- whether migration duration or locking could matter
- whether current Development data has characteristics that need to be checked before execution

Where live data inspection would be required, define read-only queries only.

Do not execute them yet unless explicitly safe and necessary.
