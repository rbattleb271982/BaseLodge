Goal

A Ski Day means:

Trips, RSVPs, itinerary dates, and Mountains Visited must never automatically create Ski Days in this task.

Create the SkiDay model
Add the minimum canonical model with:
id — primary key
user_id — required FK to User
resort_id — required FK to Resort
ski_date — required DATE
source — required string using an application-controlled vocabulary
trip_id — nullable FK to SkiTrip, provenance/reference only
confirmed_at — required timestamp
created_at — required timestamp
updated_at — required timestamp
Do not add discipline yet.
Do not infer ski vs snowboard from the user's profile.
Canonical uniqueness rule
Add a database-level unique constraint on:
user_id + resort_id + ski_date
The same user must not be able to have two Ski Day records for the same resort on the same calendar date.
However:
the same user may have different resorts on the same date
multiple users may have the same resort/date
Trip relationship
trip_id is optional provenance only.
A confirmed Ski Day must remain valid independently of its originating Trip.
Configure the relationship so:
editing trip dates does not modify Ski Days
editing trip resort does not modify Ski Days
making a trip private does not modify Ski Days
leaving/changing RSVP does not modify Ski Days
deleting a Trip does not delete its Ski Days
deleting a Trip sets associated SkiDay.trip_id to NULL
Use nullable trip_id with appropriate ON DELETE SET NULL behavior.
Explicitly verify that existing trip deletion logic does not manually delete Ski Days.
Resort relationship
Ski Days must reference canonical Resort.id.
Do not store mountain names as the canonical resort identity.
Do not allow routine Resort deletion to silently destroy historical Ski Day records.
Use restrictive FK/deletion behavior appropriate to the existing database architecture.
User deletion
BaseLodge's existing account deletion uses explicit cleanup.
Add Ski Day cleanup to that existing account-deletion sequence so deleting a user also deletes that user's Ski Day records.
Do not affect other users' Ski Days.
