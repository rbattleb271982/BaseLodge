Goal
Make normal BaseLodge application startup read-only with respect to persistent database schema and maintenance work.
After #317:
normal application startup may:
validate runtime configuration
initialize Flask/extensions
establish DB connections
initialize non-mutating caches/services

serve requests

CREATE
ALTER
DROP
INSERT
UPDATE
DELETE
merely because the application starts/imports.
Legitimate request-time behavior such as the existing last_active_at heartbeat is not considered startup mutation and should remain unchanged.
