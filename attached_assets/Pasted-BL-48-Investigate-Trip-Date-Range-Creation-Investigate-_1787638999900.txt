BL-48 — Investigate Trip Date-Range Creation
Investigate BL-48 — Simplify trip date-range creation before implementing anything.
Existing task requirements
The approved BL-48 requirements are:
Remove the extra Add this range confirmation step.
After a start date and end date are selected, automatically commit the completed range.
Show the committed range below the calendar using the existing remove/X affordance.
If multi-range trip creation is currently supported, preserve it and clearly allow another range to be selected.
Preserve trip status/visibility controls and existing validation.
Save Trip should become actionable once the required trip information is valid.
Do not silently collapse supported multi-range trips.
