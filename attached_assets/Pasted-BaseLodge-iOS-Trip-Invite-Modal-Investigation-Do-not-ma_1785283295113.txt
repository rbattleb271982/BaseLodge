BaseLodge — iOS Trip Invite Modal Investigation

Issue 1 — Friend list cannot scroll
• Open any trip.
• Tap Invite Friends.
• The friend list displays correctly but cannot be vertically scrolled, even though there are more friends than fit on the screen.
• Determine why touch scrolling is not working.
• Identify exactly which element is intended to own scrolling.
• Check for:
  - overflow: hidden
  - fixed-height containers
  - nested scroll views
  - IonModal / IonContent interactions
  - gesture handlers intercepting touch events
  - pointer-events issues
  - z-index overlays
  - CSS affecting momentum scrolling on iOS
  - Capacitor or Ionic scrolling configuration

Issue 2 — Search field with keyboard
• Tap inside the Search Friends field.
• When the iOS keyboard appears, the modal no longer lays out correctly.
• Search results disappear behind the keyboard and the remaining content cannot be scrolled.
• Determine whether this is caused by:
  - Capacitor Keyboard resize mode
  - IonModal sizing
  - viewport resizing
  - safe-area handling
  - fixed heights
  - keyboard event handling
  - incorrect CSS calculations
