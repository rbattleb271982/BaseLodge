# Trips → Friends' Friend Label Cleanup

Implement one tightly scoped presentation change to Trips → Friends'.

Trips → Mine is frozen.
Trips → Both is frozen and approved.
Do not redesign Trips.

The existing BaseLodge Trips visual system is authoritative.

## REQUIRED DISPLAY RULE

Change ONLY how the friend context is displayed on Trips → Friends' rows.

The rule is:

### Exactly 1 eligible friend

Show that person's FULL first and last name.

Examples:

Morgan Lee · going

Alexander Rivera · going

Do not shorten the name to first name only.

### Exactly 2 eligible friends

Do NOT show either person's name.

Display:

2 friends · going

### Exactly 3 eligible friends

Display:

3 friends · going

### 4+ eligible friends

Continue the same count-based pattern:

4 friends · going
5 friends · going
6 friends · going

etc.

## IMPORTANT RULE

As soon as the eligible friend count is 2 or greater, names disappear completely.

Therefore NEVER render constructions such as:

Morgan Lee, Taylor Kim · going

Morgan Lee + 1 other · going

Morgan Lee, Taylor Kim + 2 others · going

Friend01 + 2 others · going

The Friends' ledger should have only these two forms:

ONE FRIEND:
[First Name] [Last Name] · going

MULTIPLE FRIENDS:
[N] friends · going

## WHY

Friends' is specifically about trips the viewer's friends are taking.

When exactly one friend is associated with the canonical trip, identifying that person is useful.

When multiple friends are associated with the same canonical Trip ID, the ledger only needs to communicate the size of that friend group. The user can open the trip for participant detail.

This also keeps dense and 360px Friends' states compact.

## TWO-LINE LEDGER STRUCTURE

Preserve the current compact Friends' row:

LINE 1:
Destination / region                         Dates

LINE 2:
Friend context · going

Examples:

Morgan Lee · going

Aspen, CO                             Dec 18–24
2 friends · going

Big Sky, MT                         Dec 27–Jan 2
3 friends · going

No third information row should be introduced.
