## Approved product decisions

### Season membership

For BL-8 only, use the **June 1–May 31 inferred season window**.

This is a **local Season Snapshot inference rule**, not a new global BaseLodge canonical season definition.

Example:

* Aug 2026 → 2026/27
* Jan 2027 → 2026/27
* May 2027 → 2026/27
* Jun 2027 → 2027/28

Trips belong to the card based on `start_date`.

The card must include:

* owned trips in the inferred season
* accepted guest trips in the inferred season
* past trips from the same season
* future trips from the same season

Undated trips should remain excluded.

Do not add a `season_year` model field or migration for BL-8.

### Fixed card

The Winter Card must remain a **hard fixed 4:5 aspect ratio**.

Do not:

* let it grow taller
* use internal scrolling
* use `+N more`
* truncate trips
* intentionally clip content

Every trip must remain visible within the card.

### Density system

Use the approved adaptive system:

* **1–3 trips:** 1 column, Georgia destinations, large editorial treatment
* **4–7 trips:** 1 column, Georgia destinations, reduced scale
* **8–11 trips:** 2 columns, system sans destinations
* **12–20 trips:** 3 columns, compact system sans
* **21+ trips:** ultra-compact 3-column fallback

Use progressively tighter spacing/type for dense states.

### Month grouping

Show months once per logical group where practical.

Chronological reading order must be:

**top-to-bottom column 1 → top-to-bottom column 2 → top-to-bottom column 3**

If a month group must split across columns to preserve the fixed 4:5 layout, repeat the month label in the continuation column using the muted continuation treatment from the approved plan.

### Header

Header should contain:

**[Name]’s 2026/27 Winter**
**SKIER · ADVANCED · IKON**
**in BaseLodge**

Support:

* long names
* 0 passes
* 1 pass
* 2 passes
* 3 passes

Pass behavior:

* 0 passes → separate `NO PASS`
* 1 pass → inline with rider/skill metadata
* 2–3 passes → separate pass row

Do not truncate.

### Typography

Reuse the existing BaseLodge typography system.

Use:

* Georgia / serif for headline, `in BaseLodge`, and destinations at 1–7 trips
* system sans-serif for metadata, months, and destinations at 8+ trips

Do not introduce a new font family.

### Trip content

Show only:

* month
* destination

Do not show:

* exact dates
* country/state
* trip duration
* nights
* trip status
* trip count
* country count
* date-range summary

Remove the existing **This Winter** element inside the card.

Do not redesign or remove `.ss-tagline` or other surrounding Season-screen content.
