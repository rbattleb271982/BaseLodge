Implement Task #247 — Fix Resort Selector Desktop Rendering.

The #245 resort selector for Mountains Visited + Wishlist is rendering incorrectly on desktop. The country/state accordion headers appear as native gray browser buttons, the chevron SVG renders at approximately 300×150px, and text such as "United States 8 visited" runs together.

The goal is to fix ONLY the desktop rendering problem while preserving all #245 functionality and the existing mobile experience.

IMPORTANT:
- Do NOT change the approved #245 information architecture.
- Do NOT change the hierarchy: United States first → state/province → resort.
- Do NOT change search, sorting, selection, AJAX behavior, or the Wishlist 15-resort limit.
- Do NOT change backend/routes/models/database.
- Do NOT modify unrelated pages or styles.
- Do NOT publish or push to GitHub.
- Do NOT replace the <button> elements with divs unless the CSS fixes below demonstrably fail.

STEP 1 — Restart / CSS verification

Restart the Flask server so STYLES_VERSION is recomputed from the current static/styles.css hash.

Then hard-refresh the Mountains Visited owner page in a desktop browser.

Verify that the .rs-* rules from static/styles.css are actually being loaded. If they are loaded, continue with the CSS/HTML fixes below.

STEP 2 — Fix native button appearance

In static/styles.css, update the existing .rs-country-row and .rs-state-row rule to include:

appearance: none;
-webkit-appearance: none;

Do not otherwise redesign these controls.

The buttons should render as flat BaseLodge-styled rows with:
- no native gray browser background
- no native border
- the existing flex layout
- the existing BaseLodge typography
- a small muted chevron
- correct spacing

STEP 3 — Fix chevron sizing

In templates/partials/resort_selector.html, find the chevronSvg() generator.

Add explicit HTML dimensions to the generated SVG:

width="15" height="15"

Do not change the SVG artwork itself.

The chevron should render approximately 15×15px, muted gray, and rotate 90° when its section is expanded.

STEP 4 — Verify layout

Use DevTools or equivalent inspection to confirm that:

.rs-country-row
- display: flex
- appearance: none
- correct full-width layout
- chevron approximately 15×15px

.rs-state-row
- display: flex
- appearance: none
- correct indentation
- chevron approximately 15×15px

Country headers should clearly display:

United States    8 visited

with appropriate visual separation between the name and count.

State headers should display the full state/province name rather than only the state abbreviation.

Resort rows should display:

Resort Name                              ○

with the circular checkbox on the right.

STEP 5 — Fallback only if necessary

ONLY if the CSS fixes above fail and the <button> elements still cannot reliably render the intended flex layout, replace the country/state header buttons with:

<div role="button" tabindex="0">

and update the accordion keyboard/click handling accordingly.

Do NOT do this preemptively. Native <button> semantics are preferable if the CSS fixes work.
