## Actions to Take

Actions to Take belongs structurally WITH Your Next Trip.

It is the viewer's own trip-planning work.

It is NOT:
- Needs You
- a social request
- a separate task manager
- a blush state
- a checkbox/to-do system

Locked behavior:

- Actions to Take is attached to the Next Trip module.
- It is expandable/collapsible.
- Default state is OPEN / expanded.
- Collapsed state must still show:
  - that unresolved actions exist
  - the unresolved count
- Expanded state shows the individual actions inline.
- Existing action semantics and write behavior must be reused.
- Blush must NOT be used for Actions to Take.
- Use a quiet contained/divided treatment consistent with the selected J trip module direction.

The selected visual direction from exploration was:
- one Next Trip surface
- Actions to Take as a second internal zone
- divider between trip summary and actions
- no blush
- no checkbox decoration
- no MINE/THEM language
- no OPEN task register
