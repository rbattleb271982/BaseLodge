1. DO NOT ADD A LOADING ICON
==================================================

Do NOT add:

- spinner
- progress ring
- static loading icon
- animated dots
- mountain icon
- ski icon
- additional logo

We specifically do not want a static spinner/icon because if it is not visibly moving it can make the app appear even more stuck.

Text only.

==================================================
2. LOADING TEXT STYLE
==================================================

“Loading” should be:

- centered
- above the BaseLodge logo
- visually secondary to the logo
- subtle
- consistent with existing BaseLodge typography/colors

Preferred treatment:

- existing body/sans-serif font
- muted gray/taupe color similar to the tagline
- smaller than the BaseLodge logo
- enough spacing below it so the logo remains the primary visual element

Do NOT make “Loading” maroon and dominant.

The hierarchy should remain:

1. BaseLodge logo
2. Loading state
3. Tagline

Even though Loading physically appears above the logo.
