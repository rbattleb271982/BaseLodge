BL-109 PRODUCT CONTRACT

Objective:
Close the loop for users who suggest that two people know each other by letting the suggester know when those people later connect in BaseLodge.

Required eventual behavior:

1. User A suggests User B ↔ User C.
2. BaseLodge retains:
   - suggester/introducer;
   - suggested user B;
   - suggested user C;
   - suggestion timestamp.
3. If B and C later become connected in BaseLodge, BaseLodge can match that connection to the earlier suggestion.
4. User A receives a lightweight confirmation, preferably through the existing Happening system.
5. No manual confirmation is required from B or C.
6. If multiple people suggested the same pair, each qualifying suggester may receive confirmation.
7. Do not assign exclusive credit.
8. User-facing language must say the user "suggested they knew each other," not that the user caused the connection.
9. Do not expose messages, conversations, private activity, or additional relationship information.
10. Do not create public introduction scores, counts, badges, leaderboards, or similar gamification.
11. Preserve suggestion/conversion information for potential future network intelligence.
