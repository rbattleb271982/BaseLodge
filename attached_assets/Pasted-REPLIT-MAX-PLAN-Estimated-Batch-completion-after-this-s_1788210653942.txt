==================================================

Reducing query count must not simply replace N+1 queries with huge joins or unnecessary sensitive-data loading.

- row multiplication
- memory usage
- unnecessary columns/relationships
- authorization boundaries
- expected cardinality

Prefer bounded, understandable queries.
