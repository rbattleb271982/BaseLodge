# Background

Historically, BaseLodge invite links opened the mobile website instead of the native application, which created a confusing experience.

Example:

https://app.baselodgeapp.com/invite/<token>

If someone already had the BaseLodge app installed, tapping the invite should open the app—not the mobile website.

We redesigned the intended architecture so there would be one canonical invite URL.

Desired behavior:

• User has app installed
→ Universal Link / Android App Link opens BaseLodge directly.

• User does not have app installed
→ Mobile invite landing page opens.

• User installs the app
→ Original invite token is preserved.

• User signs in
→ Original invite resumes automatically.

• User creates an account
→ Original invite resumes automatically.

• User finishes onboarding
→ Original invite resumes automatically.

• User is already inside the Capacitor app
→ Internal navigation occurs instead of attempting another deep link.

We also previously removed the old custom URL scheme approach (baselodge://friends) and replaced it with Universal Link/App Link behavior.

I am NOT sure whether those changes made it into the production native builds.
