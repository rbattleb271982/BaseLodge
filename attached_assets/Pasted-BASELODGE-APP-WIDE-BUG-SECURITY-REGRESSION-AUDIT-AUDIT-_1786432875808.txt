AUDIT ONLY.

DO NOT modify code.

The goal is to systematically identify real functional bugs, authorization gaps, data-integrity risks, stale code paths, and frontend/backend mismatches across the entire BaseLodge app.

Recent work has already stabilized:

- Trip Detail inline Edit mode
- My Setup
- Trip Planning

Now perform a broad application audit before additional feature work.

==================================================
1. ROUTE INVENTORY
==================================================

Inventory every Flask route.

For each route return:

- route
- HTTP method(s)
- handler/function
- login requirement
- ownership/member/admin restrictions
- purpose
- known frontend/template callers
- ACTIVE / LEGACY / DEAD / UNKNOWN

Flag:

- routes with no callers
- duplicate routes
- routes superseded by newer routes
- state-changing GET routes
- unexpected public routes
- suspicious auth gaps

Do not remove anything.

- edit/delete someone else's planning post
