==================================================

Implement a dedicated isolated capture runtime.

Required identity:

BASELODGE_CAPTURE_MODE=1

The capture workflow MUST fail closed unless both conditions are true.

It must never use the normal Development or Production database.

Use a disposable SQLite database under `/tmp` unless the existing architecture strongly requires the already-approved in-memory test strategy.

The capture database must:

- be created fresh
- exist only for the capture workflow
- contain synthetic data only
- be disposable
- never connect to Supabase
- never connect to Production
- never connect to Development
- be deleted during cleanup

Add explicit guards that refuse capture startup if the resolved database identity is not safe.

Do not modify normal runtime database behavior.
