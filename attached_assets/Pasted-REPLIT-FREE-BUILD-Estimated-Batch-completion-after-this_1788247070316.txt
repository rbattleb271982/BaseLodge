3. PROVISIONAL CUSTOM ALERT POLICY

Document the candidate thresholds from Task #417, including:
- same route + exception grouping
- overall 5xx rate
- sustained route slowness
- severe latency
- provider degradation/outage

- window
- minimum volume
- severity
- grouping
- cooldown
- recovery rule

Clearly label every custom threshold PROVISIONAL.

4. ACTIVATION GATE

Custom alerts MUST NOT be activated until:

- at least 14 representative Production days exist
- at least 1,000 Production requests have been observed
- thresholds have been recalibrated against that baseline
- an independently approved aggregation/delivery service exists

Reference the separate baseline task rather than implementing measurement here.

5. NATIVE AVAILABILITY MONITORING

Do not change deployment configuration.

6. SAFE ALERT PAYLOAD

Document the approved allowlist and privacy exclusions from Task #417.

- user identity
- email
- IP
- request contents
- raw URL/query
