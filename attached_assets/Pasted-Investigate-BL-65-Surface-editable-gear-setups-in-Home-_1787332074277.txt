## Desired behavior

On the Home tab/profile summary area where the user currently sees information such as:

**Skier · Level · Pass**

we want to surface the user's gear directly underneath.

### User has no gear

Show an underlined callout:

**Add your gear**

This should clearly look tappable/editable.

Tapping it should take the user to the existing Profile area where gear can already be added or edited.

Do not create a second gear-entry workflow.

### User has gear

Replace the empty-state callout with the user's primary setup.

For a skier, display the primary ski setup on a single line.

For a snowboarder, display the primary snowboard setup on a single line.

If the user is both a skier **and** snowboarder and has entered both setups, show **both** setups.

The gear display should remain concise and fit naturally into the existing Home profile summary.

The displayed gear should also be **underlined/tappable** so it is obvious that it can be edited.

Tapping existing gear should take the user to the same existing Profile gear-editing experience.
